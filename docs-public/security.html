Responsible disclosure

Do not post credentials, private data, unpublished prediction evidence, or exploit details in a public Issue. Use the repository Security area when private vulnerability reporting is available, or contact the repository owner through the GitHub profile.

Public-content controls

The publication gate rejects symbolic links, oversized or unapproved files, broken or escaping links, non-allowlisted external hosts, private-network addresses, local filesystem paths, and common credential patterns. Deployment remains blocked until an audit passes on the exact source commit.

Public documentation only. No prediction, registry, or production authority is granted here.
