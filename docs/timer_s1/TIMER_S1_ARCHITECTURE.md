# Timer-S1 architecture

```text
JSON request
  -> strict TimerS1Request
  -> chronology and structural game geometry
  -> immutable provenance manifest
  -> approved remote-code allowlist
  -> PR-A stop boundary
  -> EXECUTION_PENDING response
```

PR-B may insert an isolated Transformers runtime only after every preceding gate passes. The
mirror repository is metadata only and has no automatic fallback path until complete byte parity
is independently proven.
