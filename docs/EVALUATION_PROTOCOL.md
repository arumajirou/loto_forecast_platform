# 評価プロトコル

1. 内側Rolling CVで特徴量・パラメータ・重み・校正器を選ぶ。
2. 外側Rolling CVでモデルファミリーを比較する。
3. 固定Holdoutは候補選択に使わない。
4. 将来予測を抽選前に封印し、最低20回、正式50回評価する。
5. 主指標は平均Hits@7。校正非劣性を必須ゲートにする。
6. seedは探索1、外側候補3、曖昧時5、認定10へ適応的に増やす。
7. bootstrapの単位は抽選。位置を独立標本としてMcNemarへ平坦化しない。
8. χ²検定で帰無仮説を棄却できないことは一様性の証明でも理論上限の証明でもない。
9. e-processは片側採用判定に使い、低いe-valueを逆方向棄却の証拠にしない。
10. Holdoutを見た後の変更は新しい実験世代とする。
