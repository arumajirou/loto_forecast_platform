# Platform Metrics v1 Cardinality Budget

## Budget contract

```text
maximum catalog upper bound: 25,000 series
maximum single metric-family upper bound: 5,000 series
current catalog upper bound: 10,412 series
current maximum family: 4,680 series
current maximum family name: loto_model_inference_duration_seconds
```

The bound assumes every approved label combination is touched. Runtime use is lazy and should normally
create far fewer series.

## Conservative formula

For each metric family:

```text
label_product = product(size of every finite label allowlist)
```

Multipliers:

```text
Gauge      = 1
Counter    = 2
Histogram  = reviewed_bucket_count + 4
```

The counter multiplier includes the value series and the Python client's created-timestamp series. The
histogram multiplier includes reviewed buckets, the implicit `+Inf` bucket, count, sum and created
timestamp. Environments that disable created-timestamp series will use fewer series than this bound.

actual exposed series count does not exceed the declared catalog upper bound.
