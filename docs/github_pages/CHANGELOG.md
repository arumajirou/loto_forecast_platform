# Changelog — GitHub Pages Public-Docs Foundation

## 0.1.0 — 2026-08-06

### Added

- explicit public-only static source under `docs-public/**`;
- strict public-content policy and audit/build CLI;
- positive, negative, traversal, secret, link, and deterministic-build tests;
- requirements, runbook, activation gate, verification report, handoff, manifest, and SHA-256.

### Deliberately not added

- Pages deployment workflow;
- repository or Pages visibility changes;
- custom domain;
- root dependencies or lock changes;
- private data, actuals, predictions, artifacts, credentials, or callback URLs.

### Focused verification

- strict audit and deterministic build passed;
- compileall passed;
- focused pytest passed with 5 tests;
- line-length, focused secret-pattern, file-size, and SHA-256 checks passed;
- Ruff was unavailable and is not represented as passed.
