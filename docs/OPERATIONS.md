# 運用設計

## 本番SLO

取得/検証15分、Canonical/特徴量20分、再学習90分、校正/デコード30分、封印/登録20分、予備25分。合計180分。

## 定期処理

- 新抽選追加時: 固定Champion再学習、OOF校正再構築、次回予測封印
- 10抽選ごと: 正式再探索
- 日次: 増分バックアップ
- 週次: 完全バックアップ
- 月次: オフライン複製とリストア試験

## 障害

- データ不一致、リーク、署名失敗: 即停止
- 一時通信障害: 指数バックオフ
- OOM: 許可範囲内の新trialとして再実行
- Champion切替失敗: 直前Releaseへ復帰

## 起動

`deploy/systemd`のuser unitを配置し、`systemctl --user enable --now`で有効化する。
