# Artifact Manifest

Timer-owned artifacts are limited to:

- isolated environment declaration;
- campaign configuration;
- provider runner;
- strict adapter contracts and provider skeleton;
- game, chronology, and provenance modules;
- pending remote-code review;
- focused tests;
- the twelve required documentation artifacts.

No model weight, raw data, prediction, lockfile, root dependency change, shared integration,
or workflow change is part of PR-A. `SHA256SUMS` covers every Timer-owned file except itself.
