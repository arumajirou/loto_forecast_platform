# Uni2TS Package and Source Separation

The package lane pins PyPI `uni2ts==2.0.0` and its wheel/sdist SHA-256 values. The source-audit
lane separately records `SalesforceAIResearch/uni2ts` revision
`cfd46d4510ed8896f263116f32928eede05b0a75`.

No claim is made that current GitHub `main`, that source revision, and the published wheel are
byte-identical. A later target-host audit must inventory wheel files and source files and publish a
reviewed package/source diff before runtime promotion.
