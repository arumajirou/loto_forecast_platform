# Chronos-2 Changelog

## 0.1.0 - 2026-08-05

- Added strict Provider Contract v2.
- Added arbitrary GameGeometry and six game presets.
- Added position-local, position-panel, and position-multivariate layouts.

- Added snapshot/package manifests and SHA-256 inventory.
- Added schema-v1 Loto7 compatibility adapter.
- Added separate-process reference reload runner path.
- Added CPU mock tests and GPU evidence schema.
